# jerry1993-tech.github.io

Personal website of **Cornucopia.AI** — AI Full-Stack Engineer.

Live at **https://jerry1993-tech.github.io**

## Stack

Plain HTML, CSS, and JavaScript. No build step. GitHub Pages serves the `main` branch from the repository root.

## Editing

Update `index.html` and the files in `assets/`, then commit and push to `main`. GitHub Pages redeploys automatically.

The GitHub statistics shown on the page are refreshed client-side from the GitHub REST API, with static fallbacks in the markup.
